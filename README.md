# Libft

## Description
Libft is a custom C library that recreates several standard C library functions and introduces additional utility functions.

The goal of this project is to understand how common C functions work and to build a reusable library.

## Compilation

Run `make` to compile the library.

The compilation generates `libft.a`.

## Usage

Include `libft.h` in your C source files
and link against `libft.a` when compiling.
